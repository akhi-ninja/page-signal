Cost per completed page is not cost per successfully reviewed whole document. The second sequential run received cached provider tokens; its small cost difference cannot be attributed to LangGraph. Provider variability, fixed run order, caching, initialization and network conditions confound timing/output differences. No repeated/randomized trial or significance test was performed.

The comparison file flags 13 observed metric drops at a zero-drop diagnostic threshold. This is a review signal, not a calibrated release threshold. Preserve these reports unchanged; do not loosen the scorer after seeing results to manufacture improvement.

Limitations: all inputs are synthetic. The scanned PDF uses an explicit fixture transcript fallback, so this does not benchmark OCR quality. The drawn-stroke sample is artificial and not human handwriting. Transcript evidence scoring penalizes image-supported values absent from supplied text. Classification scoring requires exact labels even though the extractor uses open vocabulary; contract-category strict label/form matches were 0/5 for both engines, and the retained sanitized report cannot diagnose alternative labels. This remains a measurement limitation to investigate, not proof that every contract was unidentified. The small corpus is not representative of all document types, languages, handwriting, real scans, or commercial workflows.

This experiment did not exercise background queue delivery, authenticated preview jobs, automatic crops, complete mixed-PDF grouping accuracy, cross-page table joining or human review time. SQL restart/ownership/retention and crop pixel behavior have separate deterministic tests. Live operational validation and representative authorized samples remain pending.
