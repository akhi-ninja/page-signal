## Where the score lost points

- The custom application form with repeated labels and checkboxes had 60% field precision, 75% nonblank recall and 66.7% field coverage. It is the largest measured weakness. Values that fail matching are not automatically proven hallucinations: exact section/label/occurrence matching and checkbox representation can also cause mismatches.
- Both agreement pages failed the strict classification check while their annotated field values matched. The check requires an exact machine document type and form number. This report does not retain raw outputs, so it cannot distinguish a legitimate alternative type label from a wrong identity; add sanitized classification diagnostics before changing prompts or ground truth.
- The low-contrast invoice and corrupted-OCR invoice each omitted an annotated blank field under the exact matching policy.
- The corrupted-OCR invoice recovered all nonblank values from the page image, but transcript evidence recall was 60%. An image-correct value can disagree with corrupted OCR. A failed transcript check must remain a review signal, not grounds to silently delete or "correct" the value.

## Interpretation limits

This is a starter contract benchmark, **not PageSignal's accuracy across all documents**. It contains nine small printed pages; four are related invoice variants, so the samples are not independent. The clean, rotated, upside-down and low-contrast cases generally receive the synthetic reference transcript; only one case deliberately corrupts it. The run therefore measures OCR-assisted extraction, not the actual Tesseract/PDF text-reading pipeline or vision-only robustness.

The corpus does not yet establish handwriting, multilingual, dense-layout, mixed-document, real insurance form or production load performance. Two pages belong to a demonstration agreement, but extraction was per page; there was no measured cross-page reconciliation. No live simple-pipeline comparison was run, so these numbers do not establish a LangGraph advantage. Confidence intervals and release thresholds would be misleading with this small correlated corpus.

## Next implementation priorities

1. Add non-sensitive mismatch diagnostics for classification, field labels/sections and checkbox state before deciding whether misses are semantic errors or scoring-contract differences.
2. Add independent, authorized difficult-document fixtures, actual browser OCR/PDF ingestion and representative handwriting/multilingual cases.
3. Improve repeated-field association and checkbox handling, then rerun against this unchanged baseline with the same model, fixtures and budgets.
4. Compare the simple pipeline and targeted rechecks under explicit budgets before enabling automatic extra AI calls or publishing a general accuracy claim.
