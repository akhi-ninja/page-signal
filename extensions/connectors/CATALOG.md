# Provider catalog and discovery

Catalog-only entries are integration targets, not working adapters. NHTSA and SEC read operations are documented from official references; no live calls were tested. Monogram icons are placeholders, not official logos. Semantic discovery accepts an injected proposer and validates every returned evidence ID against raw response values. It is not an implemented AI model. Entity, period, currency, scope and independent-source validation remain required before using a recommendation. No network or credential handling.
