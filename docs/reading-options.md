# Bounded reading and source geometry

The workspace Reading options section applies to new uploads. Users can select English or English plus Spanish, French, Hindi, Tamil or Malayalam, and explicitly rotate pages by 0/90/180/270 degrees. At most three allowlisted OCR languages are supported by the pure option validator. A language change terminates the previous serialized Tesseract worker before loading the selected models. Model downloads can take time; selecting a language is not an accuracy guarantee or automatic language detection.

Original files stay unchanged. Images render to a separate white-backed canvas with a maximum 2300-pixel edge, 8-million-pixel budget and 3x enlargement cap. Enlargement does not recover missing information. Image metadata records original/rendered dimensions, quarter-turn rotation and an affine original-to-rendered pixel matrix. Preview, OCR word coordinates and submitted AI images use the same upright normalized coordinate frame. Source crops are taken from the upright preview. PDF native rotation and the user's rotation are combined through PDF.js viewports, and recorded separately. PDF vector-page units are not mistaken for original scan pixel density.

Low-resolution checks use original image dimensions, so upsampling cannot hide a small source. Scan hints include contrast/blank heuristics and a sampled Laplacian variance hint for possible blur. These are review prompts, not confidence percentages or proof of readability. No arbitrary sharpening, deskewing, orientation detection or pixel-value repair is performed. Automatic orientation remains `orientation_checked:false`; the recorded rotation is an explicit user choice. A local text-empty result is marked `unreadable_local_text` rather than claiming successful reading. AI may still read page pixels when OCR has no text.

Workspace JSON records reading options, per-page preprocessing transforms and local reading status. Extracted values keep original_value on first edit or accepted crop proposal. Repeated/requested field names remain distinct in exports instead of overwriting each other.

Validation uses actual raster pixels for every quarter-turn and bounded affine corner geometry, plus PDF text-coordinate tests, malformed-language/rotation rejection and export-review UI tests. Real handwriting, automatic skew/orientation, OCR quality by language and representative review time remain measured-study work. The existing synthetic paired benchmark includes controlled PDF/scan examples but does not establish those broader claims.
