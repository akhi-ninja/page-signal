Open-source document extraction, with review built in

PageSignal helps turn PDFs and scanned images into document identities, editable fields, tables and structured JSON. It is designed to work across document types rather than restricting you to one business or a fixed list of forms. AI results depend on readable source material and need verification.

From document to JSON

Upload supported files, run AI extraction, compare values with the original, request selected fields, and export the reviewed result. Read the PDF and scan to JSON guide for the full workflow and current limits.

Build into your application

Native React, Angular and Vue components connect through your own backend adapter. Server-side core and SDK packages support extraction services. Compare the framework packages and integration options.

Inspect and self-host

The MIT-licensed source code is available to inspect, adapt and self-host. Provider usage and hosting are separate costs. Find setup instructions in the documentation and changes in the release history.

New here? Start with the document extraction guides. The public documentation is available without login; hosted uploads and processing require sign-in.
