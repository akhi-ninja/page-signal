How to convert PDFs and scanned documents to JSON

A document is easy to read but often difficult to use in software. PageSignal provides an open-source workspace for identifying document types, extracting information, reviewing it alongside the source, and exporting JSON.

1. Start with a readable PDF or image

Open the PageSignal workspace and sign in with a configured provider. Drag files into the upload area or choose Browse files. Supported formats are PDF, PNG, JPEG, WebP and BMP. A batch can contain up to 10 files, with a 30 MiB limit per file and a 100 MiB combined limit. PDFs can contain up to 40 pages. These are application limits, not a statement of the AI provider’s maximum limits.

A PDF may already contain a text layer. A scanned PDF or image needs optical character recognition (OCR). Local OCR currently uses English recognition. Clear, upright pages with readable text produce a better starting point; low-resolution photos, shadows, handwriting and overlapping marks can reduce accuracy.

2. Identify the document and extract information

Use the primary AI action in Extraction review, or enable AI extraction before uploading. Review the confirmation before sending page images and extracted text to the configured AI service. The application can process multiple documents in a bounded queue; you do not need to start each one separately.

Document identification is open vocabulary: it is not restricted to a fixed list of industries or forms. The AI attempts to identify a document’s title, type, issuer and form details where visible. Ambiguous or unreadable content can remain unknown or require review. A file containing distinct forms may be reported as mixed documents.

3. Review the fields against the original

The review workspace places fields beside the source preview. Select a field or citation to navigate to its page and locate supporting text when a reliable match exists. Inspect repeated labels, dates, identifiers, checkboxes and table rows carefully. A matching label is not proof that the value has been read correctly.

Correct errors before exporting. Missing or illegible information should remain empty or null rather than becoming a plausible guess. Precise highlighting depends on available PDF text or OCR positions; a poor scan may support page navigation without an exact highlight.

4. Ask for specific information

If you need selected values, enter the labels in Find specific fields. For example: “Find the reference number, issue date and total amount.” Use Ask for a follow-up question about the document. The current query flow searches supplied numbered page text and successful extracted field information; it does not independently reread the original images. Run vision extraction first when OCR is unclear, and verify the returned evidence.

5. Export structured JSON

Export the selected document after reviewing its values. The web export includes schema version, fields, evidence and source metadata, with additional page and classification information for AI results. It differs from a single-page API response. The abbreviated example below illustrates common properties; see the output format documentation for details.

{
  "schema_version": "3.0",
  "document_type": "application_form",
  "fields": {
    "reference_number": "REF-2048",
    "renewal_date": null
  }
}

What happens to uploaded documents?

The current workspace holds uploads, edits and conversations in the browser tab rather than a durable document library. Export before refreshing or closing it. With AI enabled, page images, text and relevant query context pass through the server to the provider. Review the privacy notice and use a suitable deployment for your information.

For an embedded workflow, read the package integration guide. Source code is available on GitHub; self-hosting requires your own model credentials and hosting.
